# إعادة بناء كاملة لتقرير المعلومية اليومية (Daily Info Report)

## ملخص التعديل
أُعيد بناء `daily_info_module.js` بالكامل بحيث يطابق هيكل النموذج الورقي الأصلي بدقة،
ويعالج المشاكل الهيكلية الست المذكورة في طلب التعديل.

## المشاكل التي تم إصلاحها

### 1) الهيكل الأيمن المفقود (نوع الإيرادات والفترة)
- أُضيفت 3 أعمدة في أقصى يمين الجدول:
  - **نوع الإيرادات** (التصنيف الرئيسي) — يستخدم `rowspan="3"` لكل تصنيف.
  - **البيان** — نص تفصيلي لنوع الإيراد، يُكتب في كل صف.
  - **الفترة** — تأخذ القيم: `ص` (صباحي)، `م` (مسائي)، `ج` (الإجمالي).
- التصنيفات الأربعة الموجودة:
  1. المترددين على الخدمات
  2. مشاركة المجتمع
  3. المشتركة
  4. الإعفاء

### 2) دمج خلايا المطبوعات (Rowspan) في العمود الأيسر
- العمود الأيسر تم إعادة هيكلته إلى 4 أعمدة فرعية:
  - رقم المطبوعات (من)
  - رقم المطبوعات (إلى)
  - عددها
  - نوع المطبوعات
- جميع خلايا "نوع المطبوعات" و"من/إلى/عددها" تستخدم `rowspan="3"` بحيث تغطي
  صفوف (ص / م / ج) لكل تصنيف، مطابقة للنموذج الورقي:
  - تذاكر معاينة → تصنيف المترددين.
  - اسناد تحصيل مشاركة مجتمع → تصنيف مشاركة المجتمع.
  - قسائم تحصيل موارد مشتركة → تصنيف المشتركة.
  - سندات الإعفاء → تصنيف الإعفاء.
  - استمارات الفحوصات → الصفين الإجماليين النهائيين (`rowspan="2"`).

### 3) تجاوب الجدول (Responsiveness)
- الجدول مغلّف بـ `<div class="di-scroll">` يحتوي على `overflow-x: auto;`
  لتفعيل التمرير الأفقي على الشاشات الصغيرة والمتوسطة.
- جميع رؤوس الأعمدة (th) تستخدم `min-width` لمنع انضغاط النصوص:
  - تصنيف: `110px`، بيان: `220px`، فترة: `50px`، خدمات: `80px`،
    إجمالي: `95px`، تسلسل: `80px`، عددها: `70px`، نوع المطبوعات: `150px`.
- في وضع الطباعة `@media print` تم إلغاء التمرير (`overflow: visible`) ليطبع كاملاً.

### 4) ألوان متباينة بين المتصفح والطباعة
- **في وضع المتصفح (`@media screen`)**: ألوان هادئة ومريحة:
  - رؤوس وتصنيف: `#eef2ff` / `#e5e7eb` / `#f3f4f6` (بنفسجي/رمادي فاتح).
  - صفوف الإجماليات الفرعية: `#fef9c3` (أصفر هادئ).
  - الإعفاءات: `#dcfce7` (أخضر هادئ).
  - الإجمالي الكبير: `#fce7f3` / `#ede9fe` (وردي/بنفسجي هادئ).
  - زيادة في الـ padding للراحة البصرية.
- **في وضع الطباعة (`@media print`)**: تعود الألوان الحادة من النموذج الورقي
  (`#f4b9c8`, `#f7e59d`, `#fff4a8`, `#d8f0d2`, `#f7c3d0`) عبر `!important`
  مع `print-color-adjust: exact`.

### 5) إعدادات الطباعة (Print CSS)
- `@page { size: A4 landscape; margin: 0.5cm; }` — إجبار المتصفح على
  الطباعة بالعرض على ورق A4.
- نافذة الطباعة المنفصلة تحوي نفس قواعد `@page` و`@media print` لضمان
  ثبات النتيجة عبر المتصفحات.

### 6) ترويسة الصفحة (Header)
- الترويسة (كحلان عفار + الجمهورية اليمنية + اليوم/التاريخ/الموافق)
  وُضعت داخل `<div class="report-header">`.
- `@media screen { .report-header { display: none !important; } }` →
  مخفية تماماً أثناء التصفح.
- `@media print { .report-header { display: block !important; } }` →
  تظهر فقط عند الطباعة.
- نسخة الطباعة المنفصلة تحوي أيضاً الترويسة بشكل ظاهر دائماً.

## الملفات المتأثرة
- `daily_info_module.js` — إعادة بناء كاملة (المنطق + الـ HTML + الـ CSS).
- لم تتغير أي ملفات Backend ولا قاعدة البيانات.

## التوافق مع الـ API
لم يتم تغيير أي عقد بيانات. الواجهة تستهلك نفس استجابة
`GET /api/reports/daily_info?date=YYYY-MM-DD` كما هي.
